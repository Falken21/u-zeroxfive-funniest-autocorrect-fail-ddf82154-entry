A landlord sends a tenant a perfectly routine lease-renewal text — except autocorrect has swapped one letter and turned the lease into a leash. The message never notices. It carries on through the twelve-month term, the deposit deadline and the signing instructions in the same flat, businesslike tone, and then closes with the building's house rule, which lands very differently once you are picturing a leash: strictly no pets. The entry is the message exactly as received, with no framing or explanation.

## The entry

> Hi Mr. Alvarez, your new leash begins June 1st: twelve-month term, first month plus deposit due Friday. Please sign both copies and return them. Strictly no pets.

162 characters.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` with no trailing newline.
